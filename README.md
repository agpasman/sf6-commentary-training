# SF6 実況トレーニング

ストリートファイター6のeスポーツ実況練習用ツールです（GitHub Pagesで動く静的サイト）。

- **技図鑑**：CAPCOM公式サイトの技映像を、技名・ふりがな・コマンドと並べて表示します。通常技は発生フレームとガード属性付きです。
- **クイズ**：映像→技名、声に出して答える、通常技の名前↔ボタンなど。
- **試合で実況練習**：YouTubeや動画ファイルに技名タグを付け、再生中に表示します。答え合わせモードでは技の瞬間で自動的に止まります。
- **データ管理**：備考・ふりがな修正・試合タグなどを `shared.json` に書き出し、このリポジトリで差し替えると全員に反映されます。

技データは公式サイトのコマンドリスト／フレームデータから 2026-11-17 に取り込みました（`data.js`）。ふりがなは公式の読みではありません。
